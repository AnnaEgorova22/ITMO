# Отчёт о тестировании ML-сервиса

## 1. Цель тестирования

Цель тестирования — проверить работоспособность системы как единого целого:
REST API, бизнес-логику, PostgreSQL, RabbitMQ, worker-сервисы и историю операций.

---

## 2. Проверка окружения

### Действия

Запущена система командой:

```bash
docker compose up --build
```

Проверен статус контейнеров:

```bash
docker compose ps
```

### Ожидаемый результат

Все сервисы находятся в статусе `Up`.

### Фактический результат

Сервисы `app`, `web-proxy`, `database`, `rabbitmq`, `worker-1`, `worker-2` запущены.

**Статус: успешно**

---

## 3. Сценарий: регистрация пользователя

**Endpoint:**  
`POST /auth/register`

**Тестовые данные:**

```json
{

}
```

**Фактический результат:**

**Статус: успешно**

## 15. Вывод

Система корректно работает как единое целое:

- REST API функционирует

- worker-сервисы выполняют ML-задачи  
- история операций сохраняется  

Все ключевые пользовательские сценарии успешно протестированы.
